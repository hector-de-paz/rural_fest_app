# 🎉 Rural Fest

**Rural Fest** es una aplicación móvil desarrollada en **Flutter** que permite a los usuarios descubrir, crear y gestionar fiestas y festividades en zonas rurales. La aplicación utiliza **Supabase** como backend para autenticación y base de datos.

---

## 📱 Características Principales

### 🔐 Autenticación
- **Login con Google**: Inicio de sesión seguro mediante Google OAuth a través de Supabase Auth
- **Gestión de sesiones**: Persistencia automática de sesión de usuario

### 🗺️ Mapa Interactivo
- **Visualización de fiestas**: Todas las fiestas se muestran en un mapa interactivo usando `flutter_map`
- **Navegación geográfica**: Explora fiestas por ubicación
- **Marcadores personalizados**: Cada fiesta tiene su marcador en el mapa

### 🎊 Gestión de Fiestas (CRUD Completo)
- **Crear**: Añade nuevas fiestas con nombre, descripción, fecha y ubicación
- **Leer**: Visualiza todas las fiestas en lista y mapa
- **Actualizar**: Edita los detalles de tus fiestas
- **Eliminar**: Borra fiestas con actualización automática de la UI

### � Selector de Ubicación
- **Mapa interactivo**: Selecciona la ubicación exacta de la fiesta tocando el mapa
- **Geocodificación inversa**: Convierte coordenadas en direcciones legibles

### 👤 Perfil de Usuario
- **Visualización de perfil**: Muestra información del usuario (nombre, username, descripción)
- **Edición de perfil**: Actualiza tu información personal
- **Foto de perfil**: Sube y actualiza tu avatar usando `image_picker`
- **Integración con Storage**: Las imágenes se almacenan en Supabase Storage

### 🎨 Tema Personalizable
- **Sistema de temas centralizado**: Todos los colores se gestionan desde un único archivo
- **Fácil personalización**: Modifica colores principales, secundarios, fondos y textos desde `lib/theme/app_theme.dart`

## 🚀 Instalación y Configuración

### Requisitos Previos

- **Flutter SDK**: Versión 3.9.2 o superior ([Instalar Flutter](https://flutter.dev/docs/get-started/install))
- **Cuenta de Supabase**: Crea un proyecto en [supabase.com](https://supabase.com)
- **Editor de código**: VS Code, Android Studio o IntelliJ IDEA

### Pasos de Instalación

#### 1. Clonar el Repositorio
```bash
git clone <repository-url>
cd fiesta_pueblos_app
```

#### 2. Instalar Dependencias
```bash
flutter pub get
```

#### 3. Configurar Supabase

##### a) Crear las Tablas en Supabase

Ejecuta los siguientes scripts SQL en el **SQL Editor** de tu proyecto Supabase:

**Tabla `profiles`:**
```sql
create table public.profiles (
  id uuid references auth.users on delete cascade not null primary key,
  username text unique,
  full_name text,
  avatar_url text,
  description text,
  updated_at timestamp with time zone default timezone('utc'::text, now())
);

-- Habilitar Row Level Security
alter table public.profiles enable row level security;

-- Políticas de seguridad
create policy "Los perfiles son visibles para todos"
  on profiles for select
  using ( true );

create policy "Los usuarios pueden insertar su propio perfil"
  on profiles for insert
  with check ( auth.uid() = id );

create policy "Los usuarios pueden actualizar su propio perfil"
  on profiles for update
  using ( auth.uid() = id );
```

**Tabla `fiestas`:**
```sql
create table public.fiestas (
  id bigint generated by default as identity primary key,
  user_id uuid references auth.users on delete cascade not null,
  name text not null,
  description text,
  date timestamp with time zone not null,
  latitude double precision,
  longitude double precision,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- Habilitar Row Level Security
alter table public.fiestas enable row level security;

-- Políticas de seguridad
create policy "Las fiestas son visibles para todos"
  on fiestas for select
  using ( true );

create policy "Los usuarios pueden insertar sus propias fiestas"
  on fiestas for insert
  with check ( auth.uid() = user_id );

create policy "Los usuarios pueden actualizar sus propias fiestas"
  on fiestas for update
  using ( auth.uid() = user_id );

create policy "Los usuarios pueden eliminar sus propias fiestas"
  on fiestas for delete
  using ( auth.uid() = user_id );
```

##### b) Configurar Storage para Avatares

1. Ve a **Storage** en tu proyecto Supabase
2. Crea un nuevo bucket llamado `avatars`
3. Configura las políticas de acceso:

```sql
-- Permitir que todos vean los avatares
create policy "Los avatares son públicamente accesibles"
  on storage.objects for select
  using ( bucket_id = 'avatars' );

-- Permitir que los usuarios suban sus propios avatares
create policy "Los usuarios pueden subir sus propios avatares"
  on storage.objects for insert
  with check ( bucket_id = 'avatars' AND auth.uid()::text = (storage.foldername(name))[1] );

-- Permitir que los usuarios actualicen sus propios avatares
create policy "Los usuarios pueden actualizar sus propios avatares"
  on storage.objects for update
  using ( bucket_id = 'avatars' AND auth.uid()::text = (storage.foldername(name))[1] );
```

##### c) Configurar Autenticación con Google

1. Ve a **Authentication** → **Providers** en Supabase
2. Habilita **Google** como proveedor
3. Configura las credenciales OAuth de Google:
   - Crea un proyecto en [Google Cloud Console](https://console.cloud.google.com)
   - Habilita la API de Google+ 
   - Crea credenciales OAuth 2.0
   - Copia el **Client ID** y **Client Secret** a Supabase

##### d) Actualizar Credenciales en la App

Edita el archivo `lib/services/supabase_service.dart`:

```dart
static const String supabaseUrl = 'TU_SUPABASE_URL';
static const String supabaseAnonKey = 'TU_SUPABASE_ANON_KEY';
```

Puedes encontrar estas credenciales en **Settings** → **API** de tu proyecto Supabase.

#### 4. Ejecutar la Aplicación

```bash
# Para Windows
flutter run -d windows

# Para Android
flutter run -d android

# Para iOS
flutter run -d ios

# Para Web
flutter run -d chrome
```

## 🗄️ Estructura de la Base de Datos

### Diagrama de Relaciones

```
auth.users (Supabase Auth)
    ↓
    ├─→ profiles (1:1)
    │   ├─ id (PK, FK → auth.users.id)
    │   ├─ username
    │   ├─ full_name
    │   ├─ avatar_url
    │   ├─ description
    │   └─ updated_at
    │
    └─→ fiestas (1:N)
        ├─ id (PK)
        ├─ user_id (FK → auth.users.id)
        ├─ name
        ├─ description
        ├─ date
        ├─ latitude
        ├─ longitude
        └─ created_at
```

### Tabla `profiles`

| Campo | Tipo | Descripción |
|-------|------|-------------|
| `id` | `uuid` | ID del usuario (referencia a `auth.users`) |
| `username` | `text` | Nombre de usuario único |
| `full_name` | `text` | Nombre completo del usuario |
| `avatar_url` | `text` | URL de la foto de perfil |
| `description` | `text` | Biografía o descripción del usuario |
| `updated_at` | `timestamp` | Fecha de última actualización |

### Tabla `fiestas`

| Campo | Tipo | Descripción |
|-------|------|-------------|
| `id` | `bigint` | ID único de la fiesta (auto-incrementado) |
| `user_id` | `uuid` | ID del usuario creador |
| `name` | `text` | Nombre de la fiesta |
| `description` | `text` | Descripción detallada |
| `date` | `timestamp` | Fecha y hora de la fiesta |
| `latitude` | `double` | Latitud de la ubicación |
| `longitude` | `double` | Longitud de la ubicación |
| `created_at` | `timestamp` | Fecha de creación del registro |

## 🐛 Solución de Problemas Comunes

### Error: "Target of URI doesn't exist: 'package:supabase_flutter/supabase_flutter.dart'"

**Solución**: Ejecuta `flutter pub get` para instalar las dependencias.

### Error: "The argument type 'CardTheme' can't be assigned to the parameter type 'CardThemeData?'"

**Solución**: Este error ya está corregido en la versión actual. Asegúrate de usar `CardThemeData` en lugar de `CardTheme` en `app_theme.dart`.

### Las imágenes de perfil no se cargan

**Solución**: 
1. Verifica que el bucket `avatars` esté creado en Supabase Storage
2. Confirma que las políticas de acceso estén configuradas correctamente
3. Revisa que la URL de Supabase sea correcta en `supabase_service.dart`

### El mapa no se muestra

**Solución**: 
1. Verifica tu conexión a Internet
2. Asegúrate de que `flutter_map` y `latlong2` estén instalados correctamente
3. Revisa los logs de la consola para errores de red

### Error de autenticación con Google

**Solución**:
1. Verifica que las credenciales OAuth estén configuradas en Supabase
2. Confirma que el **Client ID** y **Client Secret** sean correctos
3. Asegúrate de que la URL de redirección esté configurada en Google Cloud Console
